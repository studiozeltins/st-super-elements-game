<objective>
Fan the shared wind phase out to two GPU consumers: tree canopies get a height-weighted
vertex-sway patch on POOLED cap materials (D-07), and NEW camp flag assets get a
cloth-ripple patch with a phase gradient along the flag length (D-08). Each keeps its own
character constants (canopy slow/low, flags 2-3× faster than grass — WIND-03) while reading
the SAME uniform objects as grass (WIND-01).

Purpose: success criterion 1 (all sway on one phase) and 3 (per-consumer character) need
consumers beyond grass; both chosen paths are shader-side to honor D-13 (zero per-frame CPU)
and the frozen-matrix rule.
Output: swaying canopies, one flapping flag per camp.
</objective>
