<objective>
Close Gap 1 from 08-UAT round 2 (test 3, "its ridged all the time"): the calm/windless
flag never droops during play.

Root cause (already diagnosed — do NOT re-investigate): the drape pose is gated on the
CONTINUOUS gust envelope in-shader BUT its constants make a permanent baseline lift
(FLAG.drapeLift = 0.7, always active because uWindStrength is pinned at 1 in play)
dominate. Between gusts drape can only relax to 0.30 (25 deg pitch) — a near-horizontal
banner. A real limp hang only occurs at uWindStrength 0 (the ?nowind debug flag), never
in normal play.

Fix (goal-backward): the in-shader `gust` value (gustGlsl at createCampFlag.ts:111) is
ALREADY the continuous low-wind activity signal the diagnosis asks for — it rests near 0
between gusts and rises when a gust travels through. The only defect is the FLAG drape
CONSTANTS: rebalance so lift is driven by the gust envelope, not a constant baseline.
Small idle lift + large gust lift => calm droops, gusts lift, strength 0 stays full limp.
This is a windMath change (single source, WIND-01) — the shader picks it up for free via
the flagDrapeGlsl generator. No new uniforms, no geometry change (voxel thickness stays
rejected), no createCampFlag shader-logic change beyond reconciling now-stale comments.

Purpose: the flag reads as a real cloth that hangs in the near-still baseline (D-01) and
streams when a gust rolls through — the D-01/D-12 character the UAT expected.
Output: rebalanced FLAG drape constants + test-first coverage + reconciled cloth comments;
the droop read routes to human UAT round 3.
</objective>
