  <how-to-verify>
    Open the built game (laragon-served dist/, e.g. http://localhost/ or your LAN URL —
    NOT the vite dev server, so you test the real build). Then walk this checklist:

    1. GRASS UNCHANGED (WIND-01, D-01 — the hard gate): between gusts, grass sway must
       look exactly like the pre-phase build — same gentle constant motion, same axis,
       same amplitude. If grass "feels different" at rest, FAIL and describe.
    2. GUST TRAVELS (WIND-02, D-03): stand where you can see a wide grass field. Within
       ~60s a gust should arrive as a BROAD FRONT sweeping across the field over ~3-5s —
       near blades lean before far blades. The whole field bowing at once = FAIL.
    3. GUST STRENGTH (D-04): at the gust peak, grass leans clearly (~2-3x normal), flags
       snap taut, smoke plumes kink downwind — pronounced lean, but NOT flattened to the
       ground, and combat telegraphs stay readable.
    4. CADENCE (D-02): over ~3 minutes, strong gusts should arrive roughly every 30-60s
       and NOT on a predictable beat.
    5. PER-CONSUMER CHARACTER (WIND-03): visit a camp — the flag flaps visibly FASTER
       than grass; tree canopies sway SLOWER and subtler (tops move most, trunks rigid);
       campfire smoke rises in chunky stepped puffs drifting sideways as it climbs.
    6. COHERENCE (WIND-01): during one gust, grass + flag + canopy + smoke all respond to
       the same event as it passes them. Alt-tab away 30s, return — nothing desynced.
    7. WANDER (D-05): over several minutes, the smoke drift / gust travel direction
       changes slowly — the world shouldn't feel like a fixed fan.
    8. ?nowind (D-12): reload with ?nowind — gust lean, flag flap, canopy sway, and smoke
       LATERAL drift all dead; grass base sway remains (its unchanged-look contract);
       smoke still rises straight up.
    9. ?nosmoke (D-12): reload with ?nosmoke — no smoke anywhere; everything else sways
       normally.
    10. FPS SANITY (D-13): frame rate feels unchanged vs pre-phase; no rhythmic hitches
        at gust arrival. If suspicious, run scripts/fps_playtest.py for numbers.
  </how-to-verify>
