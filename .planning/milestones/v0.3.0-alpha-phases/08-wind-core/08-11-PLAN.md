<objective>
Close Gap 2 from 08-UAT round 2 (test 4, promoted from backlog at user request): the camp
flag does not react to projectiles flying past.

Root cause (already diagnosed — do NOT re-investigate): no coupling exists between the
projectile system and flag cloth. Projectiles (createEffectSystem.spawnProjectile) carry
`.position` + a normalized velocity and ALREADY push world influence via
stampGround(x,z,...,velocity.x,velocity.z) to part the grass (line 304). The identical
pattern can push a directional impulse to nearby flags — the responder, the per-frame
hook, and the shader displacement term are simply missing.

Fix (goal-backward), mirroring stampGround end to end:
1. createCampFlag.ts owns the pooled cloth material — add per-flag impulse state
   (direction + magnitude) as mesh userData, add additive uImpulseDir/uImpulseMag uniforms
   written PER-FLAG via cloth.onBeforeRender (canonical way to vary a uniform per-mesh
   while sharing ONE material and cache key), and add a decaying direction-aligned
   displacement term in the begin_vertex patch summed on top of the plan-08-10 wind pose.
2. createMondstadtWorld.ts collects the flag cloths by name (mirror the campfireLights
   collect at :448-451), exposes a distance-gated disturbFlags(x,z,dirX,dirZ), and decays
   live flag impulses inside world.update() — so only flags near a projectile pay cost.
3. createEffectSystem.ts gains an optional disturbFlags callback fired once per live
   projectile per frame with the projectile position + NORMALIZED travel direction.
4. createGame.ts wires world.disturbFlags into the createEffectSystem constructor.

Hard constraints (both gaps): wind uniforms stay uTime/uWindDir/uWindStrength; the
projectile uniforms are additive + per-flag; pooled 'campFlag' material,
customProgramCacheKey, CR-01/CR-02 lifetime, and cloth.castShadow=false are NOT regressed;
frozen-matrix rule holds; no per-frame allocations; only flags near a projectile do work.

Purpose: the flag answers combat the way it answers the wind — a passing shot visibly
snaps it and it settles back — the reactive-world feel the UAT asked for.
Output: projectile->flag impulse pipeline; pure impulse math covered test-first; the kick
read routes to human UAT round 3.
</objective>
