<objective>
The DRY bus/compressor refactor the user flagged (AMBI-01, D-01/D-02/D-03). Introduce ONE
`createAudioBuses(getContext)` routing owner producing `master → DynamicsCompressor → destination`
with `ambient` / `music` / `sfx` sub-bus GainNodes feeding master, plus a `duck()`, per-bus gain
setters, and mute. Then migrate ALL 5 existing SFX modules OFF the raw destination onto the injected
`sfx` bus — deleting every direct-to-destination routing (no legacy path, CLAUDE.md). Wire the buses
into `createGame` construction and add the imperative Game volume/mute setters (MUSIC-03 backend).

Purpose: Single source of truth for routing + headroom (a compressor on master so layered
ambience + SFX + music never clip), and the seam every later Phase-10 system attaches to. This is a
mechanical, behavior-preserving migration for the SFX (they must sound identical) plus one new module.
Output: `createAudioBuses.ts` + 5 migrated SFX modules + createGame construction wiring + Game setters.
</objective>
