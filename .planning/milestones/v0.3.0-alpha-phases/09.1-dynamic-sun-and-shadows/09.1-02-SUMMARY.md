## Accomplishments

- **Per-frame basis rebuild (createMondstadtWorld):** `setShadowFocus` now rebuilds `sunRight`/`sunUp` from the live sun direction each frame BEFORE the existing texel snap — negating `liveSunDir` into the pre-allocated `liveLightDir` scratch, then the same two `crossVectors(...).normalize()` calls. Zero `new THREE.*` inside the method (verified).
- **setSunDirection channel:** Added to `AmbienceHandles`; copies the three numbers into `liveSunDir` and recomputes `liveSunOffset = dir * SUN_DISTANCE` in place. Consumers hold the reference; nothing is ever reassigned (mirrors `setSkyTop`).
- **Byte-exact frozen fallback:** `liveSunOffset` is seeded from the LITERAL `SUN_OFFSET` Vector3. The `!movingSunEnabled` path never calls `setSunDirection`, so `sunLight.position` stays bit-identical to the shipped `focus + SUN_OFFSET` — no float-trig round-trip (SHADOW-04).
- **Day/night is the sole sun-direction writer:** `createDayNightCycle` gained a `movingSunEnabled` param and writes `sunDir(phase)` through `ambience.setSunDirection` every frame when moving; when frozen it skips the dir write while colors STILL drift (D-10).
- **Gate:** `?nomovingsun` joined the bisect-flag list; `movingSunEnabled = dayNightEnabled && !nomovingsun && !prefers-reduced-motion` (reusing the `matchMedia` precedent). `nodaynight ⊇ nomovingsun` holds because `movingSunEnabled` is already false when `dayNightEnabled` is.
- **30Hz throttle untouched:** `createPixelRenderer`'s `shadowMap.autoUpdate=false` + every-other-frame `needsUpdate` block is unchanged; only its stale "sun is static" comment was rewritten. No new GPU cost (SHADOW-03).
- **Frame ordering unchanged:** `daynight.update()` still runs before `world.setShadowFocus()` — no new frame line.

## Decisions Made

- **Sun-position sign convention** — `setSunDirection` receives the sun-position direction (what `sunDir` returns, matching `SUN_OFFSET`); `setShadowFocus` negates it into `liveLightDir` for the light-travel Gram-Schmidt basis. Locked upstream by Plan 01's noon basis-equality test.
- **Literal-seeded offset, not normalize→remultiply** — `liveSunOffset` starts as a copy of the literal `SUN_OFFSET` and is only overwritten when `setSunDirection` fires. The frozen path leaves it untouched, guaranteeing byte-exact SHADOW-04 without any trig round-trip.
- **Throttle left alone** — per RESEARCH Pattern 4 (~0.055 texel/frame across the 20-min arc), the existing 30Hz depth refresh is sufficient; forcing per-frame `needsUpdate` would double the biggest GPU cost.
