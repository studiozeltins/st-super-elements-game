## Milestone goal

Make the world between fights feel alive — one coherent wind phase across everything that sways,
distance fog + sky depth, day/night color drift, a layered procedural ambient audio bed + region
music, lived-in wear, sparse reactive wildlife, and camera micro-feel. All client-only (zero
server publish; the day/night phase anchors from an SDK event timestamp with `Date.now()`
fallback). Weather explicitly deferred.

**Build order (dependency-forced):** wind → atmosphere/day-night → audio → wear → wildlife →
camera. Final verification: `scripts/fps_playtest.py` during a golem-class fight with ALL
ambiance enabled.

## Key accomplishments

- **One shared wind phase** — a single `createWind` module (gust envelope, traveling front,
  direction wander) drives grass, camp flags/banners, tree canopies, and campfire smoke; gusts
  travel across the field as a spatial wave; each consumer keeps its own character; `?nowind`
  kills all sway. Flag pose math (downwind swing + windless drape + projectile impulse) extracted
  test-first.
- **One color pipeline** — distance fog + sky-dome gradient + ~20min day-weighted day/night drift
  from a single source, server-anchored (SDK timestamp, `Date.now()` fallback) so all LAN players
  share the time of day; night is a blue combat-readable palette, never darkness; plaza lanterns
  fade at dusk via intensity on build-time lights.
- **Dynamic sun & shadows** (9.1) — sun direction drifts with the day/night clock on a CAPPED arc
  with per-frame texel-snapped shadow basis (no crawl under the pixel filter); `?nomovingsun`
  freezes to high-noon. FPS/human A-B gate not signed off.
- **Layered audio** (10) — master→compressor bus graph, gust-reactive procedural wind bed,
  day/night creature one-shots, grass rustle, combat ducking + region/combat music crossfade,
  persisted music/SFX volume. Human playtest gate not signed off.
- **Lived-in wear** — static footpath bake along real routes, plaza props, tuned scorch regrowth +
  ~2s grass-bend trail, pooled sprint dust.
- **Reactive wildlife** — sparse day butterflies, sprint-flush birds (hooked at the CPU
  groundInfluence stamp, never the GPU texture) with a wing one-shot, dusk/night emissive fireflies
  that never touch the combat light pool.
- **Camera feel** — character-model run lean + idle breathing + rare burst FOV kick, all zeroed by
  a persisted reduce-motion toggle; tuned for no pixel-crawl.
