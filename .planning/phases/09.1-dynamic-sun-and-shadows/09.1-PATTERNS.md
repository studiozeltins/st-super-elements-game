```typescript

  NOON_PHASE: 0.5,          // = KEYFRAMES[3].phase (midday, the day peak)
  ELEV_PEAK_DEG: 54.204,    // MUST equal SUN_OFFSET elevation asin(50/61.644) — NOT 75° (A1/Pitfall 3)
```

loose D-02 envelope. Using 75° makes the live midday sun visibly jump when `?nomovingsun` toggles.

**Pure-function + smoothstep-family shape to mirror** (`dayNightMath.ts:151-155` `smoothstep`, `:195-229` `samplePalette`):

the 0.99→0.01 wrap (RESEARCH Pattern 2 gives the concrete trig). Convention: `atan2(x,z)=azimuth`, `y=up`,
so noon reproduces normalized `SUN_OFFSET (0.4867, 0.8111, 0.3244)`.

### `src/game/world/createMondstadtWorld.ts` (world factory) — module-const basis → per-frame scratch

**Analog:** the file's own frozen basis block (`:141-154`) and the `setShadowFocus` snap (`:669-684`).

**Frozen basis to convert (D-04)** (`createMondstadtWorld.ts:141-154`):
```typescript
const SUN_OFFSET = new THREE.Vector3(30, 50, 20);
const SHADOW_FOCUS_SPAN = 45;
const SHADOW_MAP_SIZE = 1024;
// Fixed light-space basis for texel snapping (the sun never moves relative to the focus):
const sunDirection = SUN_OFFSET.clone().negate().normalize();
const sunRight = new THREE.Vector3().crossVectors(new THREE.Vector3(0, 1, 0), sunDirection).normalize();
const sunUp = new THREE.Vector3().crossVectors(sunDirection, sunRight).normalize();
const shadowFocusScratch = new THREE.Vector3();
```
These `const` basis vectors stay allocated ONCE (module/factory scope) but are now MUTATED per frame
(scratch, zero new alloc — RESEARCH Pattern 3). Add module-scope scratch: `WORLD_UP = (0,1,0)`,
`liveSunDir` (written by `setSunDirection`, initialized to the frozen dir), `liveSunOffset`, and a
`FROZEN_SUN_DIR`/`SUN_DISTANCE` (= `|SUN_OFFSET|` ≈ 61.644) for the fallback. The comment at `:148-150`
("the sun never moves relative to the focus") is now STALE — rewrite it.

**Texel-snap block to keep verbatim, swap in the live basis (D-07)** (`createMondstadtWorld.ts:669-684`):
```typescript
setShadowFocus(x, z) {
  const texelSize = (SHADOW_FOCUS_SPAN * 2) / SHADOW_MAP_SIZE;
  shadowFocusScratch.set(x, 0, z);
  const rightCoord = shadowFocusScratch.dot(sunRight);
  const upCoord = shadowFocusScratch.dot(sunUp);
  shadowFocusScratch
    .addScaledVector(sunRight, Math.round(rightCoord / texelSize) * texelSize - rightCoord)
    .addScaledVector(sunUp, Math.round(upCoord / texelSize) * texelSize - upCoord);
  sunLight.target.position.copy(shadowFocusScratch);
  sunLight.position.copy(shadowFocusScratch).add(SUN_OFFSET);
  sunLight.updateMatrixWorld(true);
  sunLight.target.updateMatrixWorld(true);
}
```
Change (D-04/D-06): FIRST rebuild the basis from `liveSunDir` into `sunRight`/`sunUp` (same two
`crossVectors(...).normalize()` calls, now per-frame into the pre-alloc scratch), compute
`liveSunOffset = liveSunDir * SUN_DISTANCE` (replacing the frozen `SUN_OFFSET.add(...)`), THEN run the
snap block above unchanged. Both `updateMatrixWorld(true)` calls stay. Zero `new THREE.Vector3()` in this
method (zero-alloc ban, RESEARCH Anti-Pattern).

**Sign convention (Open Question 1 / Pitfall 2):** `sunDir()` returns the sun-POSITION direction (matches
`SUN_OFFSET`); the Gram-Schmidt basis today uses `-SUN_OFFSET.normalize()`. Pick ONE convention:
`setSunDirection` receives the sun-position dir; `setShadowFocus` negates it for the light-travel basis.
Unit-test that at noon the rebuilt `sunRight`/`sunUp` equal the current module-const values (`:152-153`)
and `sunLight.position` at noon ≈ `focus + SUN_OFFSET`.

## Shared Patterns

### Zero-per-frame-allocation (mutate pre-alloc scratch in place)
**Source:** `createDayNightCycle.ts:44-51` (scratch Colors constructed ONCE, `.setHex()`/`.copy()` in
`apply`); `createMondstadtWorld.ts:154,673-678` (`shadowFocusScratch` reused every `setShadowFocus`).
**Apply to:** the new `liveSunDir`/`sunRight`/`sunUp`/`liveSunOffset` basis rebuild (mutate, never
`new THREE.Vector3()` in `setShadowFocus`); the `setSunDirection` write (`.set(x,y,z)` into `liveSunDir`).
`sunDir()` returns a plain number tuple — the only allocation, and it is in the pure twin, not the frame path.

### Single writer (day/night owns sun state; world owns shadow-camera mechanics)
**Source:** `createDayNightCycle.ts:17-21` doc ("the ONLY system that touches them") + `apply()` as the sole
mutator of ambience.
**Apply to:** `setSunDirection` is written ONLY by `createDayNightCycle.apply()`; `setShadowFocus` only
READS `liveSunDir` (never computes direction). Do not let two systems write the sun (RESEARCH Anti-Pattern).

### Mutate-in-place, never-reassign (shared object identity)
**Source:** `createMondstadtWorld.ts:79-82` (`AmbienceHandles` "every member mutated in place, no field ever
reassigned"); `setSkyTop` copies into the uniform.
**Apply to:** `setSunDirection` copies into the existing `liveSunDir` Vector3 (consumers hold the reference);
never swap the Vector3. `sunLight.position`/`.target.position` are `.copy()`-mutated, never reassigned.

### Perf-bisect kill-switch flag + freeze branch
**Source:** `createGame.ts:306-324` (`?nograss`/`?noshadow`/`?nowind`/`?nosmoke`/`?nodaynight`);
`createDayNightCycle.ts:88-92` (the `?nodaynight` apply-once-then-no-op freeze).
**Apply to:** `?nomovingsun` joins the flag list; its freeze is the D-10 SUBSET (sun position frozen, colors
still drift) — distinct from `?nodaynight`'s full freeze. `nodaynight ⊇ nomovingsun` (D-11).

### Pure-twin-first, vitest before renderer (D-13)
**Source:** `dayNightMath.ts` (zero-THREE) + `dayNightMath.test.ts` (the shipped floor/wrap/continuity suite).
**Apply to:** all sun-arc math lands in `dayNightMath.ts` with green vitest (floor invariant, noon peak, wrap
continuity, dawn/dusk asymmetry) BEFORE the `createMondstadtWorld`/`createDayNightCycle` wiring.
