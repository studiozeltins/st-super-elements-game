# Phase 10 — UI Design Contract

> Visual and interaction contract for the ONLY user-facing UI in this phase: the audio settings
> controls (MUSIC-03) added to the EXISTING settings panel. Everything else in Phase 10 is
> non-visual WebAudio plumbing. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope (tight):** add a `SKAŅA` (Audio) section to `src/ui/SettingsScreen.tsx` — a Music volume
slider, an SFX volume slider, a Music mute toggle, an SFX mute toggle — persisted to `localStorage`
under `settings.musicVolume` / `settings.sfxVolume` / `settings.musicMuted` / `settings.sfxMuted`,
mirroring the existing `settings.*` pattern (D-13). No new screen, no new visual system. Reuse the
existing `Modal`, `Toggle`, `.settings__section`, and `.settings__field` idioms verbatim.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-rolled CSS custom-property token system — "quiet-glass / Frost") |
| Preset | not applicable |
| Component library | Radix primitives (`@radix-ui/react-switch` for `Toggle`, Radix portal `Modal`) — NO shadcn |
| Icon library | none (no icon needed; chevrons/marks drawn with CSS gradients) |
| Font | `--font-body` = 'Chakra Petch', sans-serif · `--font-display` = 'Handjet Variable', monospace (both self-hosted, latin-ext subset for Latvian diacritics) |

**Token source of truth:** `:root` in `src/index.css`. The settings modal renders in a Radix portal
**outside** `.app`, so it is theme-agnostic and resolves the **base** tokens (documented in
`src/styles/hud/switcher.css`). Therefore `var(--accent)` in this panel = `#7ec843` (Mondstadt-green),
NOT the HUD Frost-cyan `#86e2ff`. **Match the sibling controls: use the `var(--accent)` token, never a
hardcoded hex.** This keeps the new sliders identical to the existing `settings__select` and `Toggle`.

## Spacing Scale

Declared values (multiples of 4, plus the panel's established odd paddings which the new controls MUST match for pixel-parity with siblings):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps, kicker-to-first-control |
| sm | 8px | Row `margin-bottom`, section top margin, field vertical padding |
| md | 12px | Row horizontal padding, label↔control gap (`.settings__field gap`) |
| lg | 16px | — |
| xl | 24px | Between major sections |
| 2xl | 32px | Modal-level breathing room |

Exceptions (inherited verbatim from existing settings controls — do NOT normalize):
- `.toggle` row padding is `11px 12px` — mute toggles reuse `Toggle` as-is, so this stays.
- `.settings__section` kicker margin is `10px 0 8px` — the `SKAŅA` kicker reuses this class.
- `.settings__field` padding is `8px 0 4px` — slider rows reuse this class.
- Slider control height target `22px` (mirrors `.toggle__switch` height) so a slider row and a toggle
  row read at the same vertical rhythm.

## Color

| Role | Value (token) | Usage |
|------|---------------|-------|
| Dominant (60%) | `--panel` `rgba(12,17,14,0.72)` over `--ink` `#0c110e` | Modal frostglass surface, slider track groove background |
| Secondary (30%) | row fill `rgba(232,245,224,0.05)` + hairline border `--line` `rgba(232,245,224,0.16)` | Toggle-row fill, slider track unfilled remainder, field separators |
| Accent (10%) | `var(--accent)` → `#7ec843` in this portal context | Slider **filled** track + thumb, toggle "on" fill, hover border, focus ring |
| Destructive | `--danger` `#ff5c3c` | Not used in this phase (only the existing Logout button uses it) |
| Text / Muted | `--text` `#e8f5e0` / `--muted` `#93a48e` | Labels / kicker + hints |

Accent reserved for (explicit list — never "all interactive elements"):
1. The **filled portion** of a volume slider track (0 → thumb).
2. The slider **thumb** (accent fill; the unfilled track and groove stay `--line`/`--panel`).
3. The **"on" state** of a mute toggle (`.toggle__switch[data-state='checked']` — already accent).
4. **Hover** border on the slider (`border-color: var(--accent)`, mirrors `.settings__select:hover`).
5. **Focus-visible** ring: `box-shadow: 0 0 0 2px color-mix(in srgb, var(--accent) 45%, transparent)`
   (mirrors `.settings__select:focus-visible`).
6. The **value % readout** numerals.

Contrast: `--text` on `--panel` and `--accent` on `--ink` both clear AA for this UI weight (same as
every existing settings control). The unfilled slider remainder must stay `--line` (low-contrast) so
the accent-filled portion reads as the value indicator.

## Copywriting Contract

All copy is Latvian, matching the existing panel voice (UPPERCASE section kickers, sentence-case labels).

| Element | Copy |
|---------|------|
| Section kicker | `SKAŅA` |
| Music volume label | `Mūzikas skaļums` |
| SFX volume label | `Efektu skaļums` |
| Value readout format | `{n}%` (integer 0–100, e.g. `70%`) — live, right-aligned in the row |
| Music mute toggle label | `Mūzika` (checked = ON / audible; unchecked = muted) |
| SFX mute toggle label | `Skaņas efekti` (checked = ON / audible; unchecked = muted) |
| Primary CTA | none — settings are live-apply (no Save/Apply button; changes take effect immediately, mirroring `onToggleFps`/`onHudThemeChange`) |
| Empty state | not applicable — no data-driven list in this UI |
| Error state | not applicable as visible UI — a corrupt/non-finite persisted value is silently clamped to `[0,1]` and falls back to the default (music 0.7, sfx 1.0). No error message is shown (V5 clamp control from RESEARCH.md §Security). |
| Destructive confirmation | none — this phase has no destructive action |

**Toggle semantics (accessibility-critical):** the mute toggles reuse the affirmative `Toggle` idiom
(like `Rādīt FPS`: checked = feature active). Checked = **unmuted/audible**; unchecked = **muted**.
Persist the inverse as the mute flag: `settings.musicMuted='1'` when the `Mūzika` toggle is unchecked
(`'0'`/absent when checked). This keeps a single, clear on/off visual state per the design constraint,
without inventing a "negative" toggle that reads backwards.

## Interaction Contract (volume slider)

The two volume sliders are styled **native `<input type="range">`** (not a custom Radix Slider) —
smallest surface, native keyboard support, matches the "no needless indirection" project rule.

| Property | Contract |
|----------|----------|
| Element | `<input type="range">` wrapped in a `.settings__field` row (label span · value % span · slider), mirroring the theme `<select>` row |
| Range | `min=0` `max=100` `step=1` (integer percent) |
| Value mapping | UI percent `n` ↔ stored gain `n/100` (0.0–1.0). Read: `Math.round(volume*100)`. Write: `setMusicVolume(n/100)` → imperative `gameRef.current.setMusicVolume()` (never derive audio state in React render — CLAUDE.md) |
| Live apply | `onChange` updates React state → `useEffect` persists to `localStorage` AND calls the imperative `Game` setter, exactly like `pixelFilter`/`showFps` |
| Keyboard | Native range: ←/→ and ↑/↓ step by 1, PageUp/PageDown by ~10, Home/End to min/max. **No custom key handling needed** — do not break native behavior |
| ARIA | Give each slider an `aria-label` (Latvian, matches visible label) and ensure the visible `%` readout is associated; native range already exposes `role="slider"` + value. Label wired via wrapping `<label>` like `.settings__field` |
| Focus-visible | `outline: none` + `box-shadow: 0 0 0 2px color-mix(in srgb, var(--accent) 45%, transparent)` — identical to `.settings__select:focus-visible` |
| Hover | Track/thumb border shifts to `var(--accent)` (mirrors `.settings__select:hover`) |
| Track fill | Filled portion (0→thumb) = `var(--accent)`; remainder = `--line` over the `--panel` groove. Thumb = accent circle, ~14–16px, hairline `--line` outer ring for definition on the glass |
| Muted state | While its mute toggle is OFF (muted), the corresponding slider dims to `opacity: 0.55` as a visual "muted" cue but **stays keyboard-operable**. Mute is independent of volume (D-13): adjusting a muted slider updates the stored volume and does **not** auto-unmute; the value is preserved and re-applied on unmute |
| Motion | Thumb/track transitions `transform`/`border-color`/`box-shadow` only, ≤0.14s (matches `.toggle` 0.14s) — no layout animation (60–144fps safe) |
| Corners | Square-ish / small radius consistent with panel (`border-radius: 8px` on the row/track, mirroring `.toggle` and `.settings__select`) |
