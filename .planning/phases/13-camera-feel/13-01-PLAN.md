    - breatheOffset(t,isMoving,reduceMotion,pixelScale): (reduceMotion || isMoving) -> 0; else sin(t*BREATHE_OMEGA)*BREATHE_AMP*pixelScale; always within +/-(BREATHE_AMP*pixelScale).
    - startKick(state): if state phase set to attack with attackRemaining = FOV_ATTACK_S (used only when NOT reduced — caller gates on reduceMotion + canKick).
    - stepFovKick(state,dt): mutates state in place (zero alloc). attack phase springs offset toward FOV_PEAK_DEG at FOV_K_ATTACK, decrements attackRemaining; when <=0 switches to release. release phase springs offset toward 0 at FOV_K_RELEASE; when |offset|<FOV_EPS_DEG snaps offset=0 and phase='idle'.
    - projectionActive(offset,wasActive): true when |offset| >= FOV_EPS_DEG OR wasActive (the one settle frame that snaps fov exactly to base).
    - canKick(now,lastKickAt): now - lastKickAt >= KICK_COOLDOWN_S.
  </behavior>
