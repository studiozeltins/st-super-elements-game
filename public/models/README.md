# Models

Drop 3D model assets here (served at `/models/...` by Vite).

## crow.glb (needed for the ground birds)

Save a **low-poly crow or raven** as `crow.glb` in this folder.

Where to get one:
- **poly.pizza** — search "crow" or "raven". Click a model → Download → glTF/GLB.
  (The "Poly by Google" ones are **CC-BY** — tell me the author so I add a credit.)
- **quaternius.com** / Quaternius packs — **CC0** (no attribution needed).
- **Sketchfab** — filter Downloadable + CC0.

Prefer CC0 to avoid an attribution obligation. Any scale/orientation is fine —
the loader auto-scales to a target height and I'll correct facing once I see it.
Bonus if it ships with an idle / peck / fly animation clip; not required.
